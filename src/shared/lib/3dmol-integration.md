# Интеграция 3Dmol.js

Для установки 3Dmol.js выполните:
```bash
npm install 3dmol
```

## Использование

3Dmol.js можно использовать для визуализации молекулярных структур каждого питательного вещества. Однако для вашего текущего проекта (гранула удобрения) это может быть избыточно, так как у вас уже есть 3D модель гранулы.

Если нужно добавить визуализацию молекул, можно создать отдельный компонент, который будет показываться при наведении на заголовок.
