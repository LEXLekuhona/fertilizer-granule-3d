# Специализированные библиотеки для химических 3D-моделей

## Текущий стек (уже используется)

✅ **Three.js + React Three Fiber** - отлично подходит для визуализации любых 3D-моделей, включая химические структуры. Ваша модель `granule-organic.glb` уже работает с этим стеком.

✅ **@react-three/drei** - предоставляет множество утилит для работы с 3D (загрузка моделей, камеры, контролы и т.д.)

## Специализированные библиотеки для химии

### 1. **Mol-Star** (Mol*)
- **Назначение**: Визуализация молекулярных структур, белков, ДНК
- **Особенности**: 
  - Поддержка форматов PDB, mmCIF, SDF, MOL2
  - Высокопроизводительный рендеринг больших структур
  - Интерактивность (выделение, измерение расстояний)
- **Установка**: `npm install molstar`
- **Когда использовать**: Если нужно работать с атомарными структурами, белками, молекулами

### 2. **3Dmol.js**
- **Назначение**: Визуализация молекулярных структур в браузере
- **Особенности**:
  - Легковесная библиотека
  - Поддержка PDB, SDF, MOL2, XYZ
  - Интеграция с React через обертки
- **Установка**: `npm install 3dmol`
- **Когда использовать**: Для простых молекулярных структур

### 3. **NGL Viewer**
- **Назначение**: Визуализация биологических макромолекул
- **Особенности**:
  - Оптимизирован для больших структур
  - Поддержка множества форматов
  - WebGL рендеринг
- **Установка**: `npm install ngl`
- **Когда использовать**: Для белков, ДНК, РНК

### 4. **Babylon.js**
- **Назначение**: Альтернатива Three.js с расширенными возможностями
- **Особенности**:
  - Лучшая производительность для сложных сцен
  - Встроенная физика
  - PBR материалы
- **Установка**: `npm install @babylonjs/core @babylonjs/loaders`
- **Когда использовать**: Если нужна более высокая производительность или физика

## Пример интеграции Mol-Star (если нужно)

```typescript
import { useEffect, useRef } from 'react'
import { Viewer } from 'molstar/build/viewer/molstar'

export const ChemicalViewer = () => {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (containerRef.current) {
      const viewer = new Viewer(containerRef.current, {
        layoutIsExpanded: false,
        layoutShowControls: false,
        layoutShowRemoteState: false,
        layoutShowSequence: false,
        layoutShowLog: false,
        layoutShowLeftPanel: false,
      })

      // Загрузка структуры
      viewer.loadStructureFromUrl('/models/structure.pdb', 'pdb')

      return () => {
        viewer.dispose()
      }
    }
  }, [])

  return <div ref={containerRef} style={{ width: '100%', height: '600px' }} />
}
```
